# 商品「首页显示控制 + 专属链接」方案

> 需求：商品管理列表新增「首页显示控制开关」与「商品链接字段」。关闭首页显示后，商品不出现在商城首页/列表，但通过专属商品链接仍可直接访问购买；相关数据统计、推广、分销逻辑保持不变（用于上架"指定链接进来才看得到"的私域商品）。

---

## 1. 需求拆解

| 能力 | 说明 |
|---|---|
| 首页显示开关 | 后台商品列表/编辑页新增「首页显示」开关（独立于现有「上架/下架」开关） |
| 商品链接字段 | 后台商品列表展示商品详情直链，点击图标一键复制 |
| 隐藏但可访问 | 关闭首页显示 → 商品从商城首页/分类/搜索列表消失；直接访问详情链接仍可购买 |
| 业务逻辑不变 | 订单、销量、佣金、推广链接、分销统计等全部保持现状 |

## 2. 现状分析（已核实代码）

| 环节 | 位置 | 现状 |
|---|---|---|
| 商品实体 | `entity/Product.java` | 有 `enabled`（上架）、`isDeleted`，**无首页显示字段** |
| 商城首页/分类/搜索列表 | `ProductRepository.findPublicProducts / findPublicProductsByKeyword` | 仅按 `isDeleted=0 AND enabled=true` 过滤 |
| 商品详情（链接直达） | `ProductServiceImpl.getProductDetail` | 仅按 `isDeleted=0 AND enabled=true` 过滤，**无列表可见性限制** |
| 分销可推广商品列表 | `DistributionServiceImpl` L1108（复用 `findPublicProducts`） | 展示 enabled 商品 |
| 后台分销总览热门商品 | `DistributionServiceImpl` L1496（复用 `findPublicProducts`） | 展示 enabled 商品 |
| 分销推广链接/海报 | `generateProductPoster` 等 | 直达 `/product/{id}`，与列表展示无关 |
| 分销统计 | 订单/佣金/点击记录 | 基于商品 ID 与订单，与列表展示无关 |
| 后台商品管理 | `web/app/admin/products/page.tsx` | 已有上架开关（`handleToggleStatus`），可复用交互模式 |

关键结论：**商品列表可见性只由 `findPublicProducts*` 两个查询控制；详情页不受列表可见性影响**。因此只需在列表查询上新增一个独立可见性字段过滤，即可实现"列表隐藏、链接可访问"，且不触碰统计/分销逻辑。

## 3. 方案设计

### 3.1 数据模型

`products` 表新增字段（**无需手动 SQL，由后端 JPA `ddl-auto: update` 启动时自动补列**）：

```java
// Product 实体
@Column(name = "homepage_visible", columnDefinition = "boolean not null default true")
private boolean homepageVisible = true;
```

- 语义：**仅控制"商城首页/分类/搜索列表是否展示"**，与「上架状态」「分销可推广（商品佣金配置）」完全独立。
- 默认 `true`：存量商品全部保持现状，无感知迁移。

### 3.2 后端改动

1. **首页/分类/搜索列表加过滤**（`ProductRepository` 两个公开列表查询追加 `AND p.homepageVisible = true`）：

```java
@Query("SELECT p FROM Product p WHERE p.isDeleted = 0 AND p.enabled = true AND p.homepageVisible = true " +
        "AND (:categoryId IS NULL OR p.categoryId = :categoryId)")
Page<Product> findPublicProducts(...);

@Query("SELECT p FROM Product p WHERE p.isDeleted = 0 AND p.enabled = true AND p.homepageVisible = true " +
        "AND (:categoryId IS NULL OR p.categoryId = :categoryId) AND LOWER(p.title) LIKE :keywordPattern")
Page<Product> findPublicProductsByKeyword(...);
```

2. **分销/统计侧解耦**：新增一个**不过滤 `homepage_visible`** 的查询，供分销与统计复用，保证"分销逻辑保持不变"：

```java
@Query("SELECT p FROM Product p WHERE p.isDeleted = 0 AND p.enabled = true")
Page<Product> findEnabledProducts(Pageable pageable);
```

   替换以下复用点（原先都复用 `findPublicProducts`，若直接加过滤会把私域商品从分销侧误删）：
   - `listPromotionProducts`（分销员「可推广商品」列表）→ 改查 `findEnabledProducts`，**可推广性继续由商品佣金配置（`product_commission` 是否存在且未排除）决定，与首页显示无关**
   - 后台分销总览「热门商品」榜 → 改查 `findEnabledProducts`，统计展示保持现状

3. **详情接口不过滤**：`getProductDetail` 保持只校验 `enabled`，不追加 `homepageVisible` 条件 → 专属链接可正常访问、加购、下单。

4. **后台接口透出字段**：
   - `getAdminProductDetail` / `listAdminProducts` 返回 `homepage_visible`
   - `updateProduct` 支持 `homepage_visible` 字段写入
   - `createProduct` 可选支持（默认 true）

### 3.3 前端改动

1. **后台商品列表表格**（`web/app/admin/products/page.tsx`）：
   - 新增「首页显示」开关列：复用现有 `handleToggleStatus` 的交互模式，点击调用 `update({ homepage_visible: !cur })`，成功 toast + 刷新列表
   - 新增「商品链接」列：`Link` 图标按钮，点击复制 `window.location.origin + /product/{id}`（当前域名即商城域名），复制成功 toast 提示；无状态直链，不参与分销
   - 编辑弹窗表单新增「首页显示」开关（与上架开关并列）

2. **类型**：`ProductDetail` 等前端类型新增 `homepage_visible: boolean`

3. **分销相关页面不改**：推广海报、分享链接、佣金统计页面全部保持现状

### 3.4 改动清单

| 文件 | 改动 |
|---|---|
| `apps/api/.../entity/Product.java` | 新增 `homepageVisible` 字段 |
| `apps/api/.../repository/ProductRepository.java` | 两个公开列表查询加 `homepageVisible` 过滤 |
| `apps/api/.../service/impl/ProductServiceImpl.java` | 后台列表/详情/更新接口透出与写入 `homepage_visible` |
| `apps/web/app/admin/products/page.tsx` | 表格加开关列 + 链接复制列 + 编辑表单开关 |
| `apps/web` 商品类型定义 | 新增 `homepage_visible` |
| 数据库 | `ALTER TABLE products ADD COLUMN homepage_visible boolean NOT NULL DEFAULT true;` |

## 4. 业务逻辑影响分析

| 业务 | 是否受影响 | 说明 |
|---|---|---|
| 商品统计（销量/销售） | 否 | 基于订单，与列表展示无关 |
| 分销佣金/结算 | 否 | 基于订单链路 |
| 推广链接/海报 | 否 | 直达详情页，详情不过滤 |
| 分销员可推广列表 | **否（独立维度）** | 可推广性由**商品佣金配置**决定；私域商品若配置了佣金，分销员在分销中心**仍可见可推广**，与首页显示互不影响 |
| 后台分销总览热门榜 | 否 | 统计展示保持现状 |
| 搜索/分类/首页 | 是（预期） | 隐藏商品不展示 |
| 直接访问详情链接 | 否 | 照常可访问、可下单 |

## 5. 风险与注意事项

1. **DB 迁移**：无需手动 SQL，后端 JPA `ddl-auto: update` 启动时自动补列（默认 `true`，存量商品可见性不变）。发布顺序：先发后端（自动建列）→ 再发前端。
2. **缓存**：商城列表若存在页面/接口缓存，关闭开关后可能有短暂延迟；本项目列表为动态请求，无 ISR 强缓存，一般实时生效。
3. **链接复制域名**：使用前端 `window.location.origin`，即商城当前部署域名，无需额外配置。
4. **隐藏商品下单**：隐藏商品加入购物车、下单、支付全部走既有流程，无额外校验。
5. **上架状态独立**：「首页显示」与「上架/下架」是两个独立开关，二者需同时满足才在列表可见（`enabled=true AND homepage_visible=true`）；上架=false 时无论首页显示与否都不可访问，避免下架商品仍可通过链接购买。
6. **分销维度独立**：「首页显示」与「分销可推广（佣金配置）」互不影响。私域商品即使首页不显示，只要配置了商品佣金，分销中心仍可被推广；如需完全私密（分销员也看不到），不配置该商品佣金即可。
